# Тест 17 — Single Responsibility Principle (SRP)

Демонстрація принципу **єдиної відповідальності** з антипатерном і рефакторингом.

## Ідея

> Клас повинен мати лише одну причину для зміни.

### Антипатерн

`UserManager` — один клас, який одночасно:
- валідує дані
- зберігає в базу
- відправляє email
- пише логи

Якщо змінюється логіка email — доводиться чіпати клас, що відповідає за збереження. Це погано.

### Рефакторинг

Кожен клас — одна задача:

| Клас | Відповідальність |
|------|-----------------|
| `UserValidator` | тільки валідація |
| `UserRepository` | тільки збереження |
| `EmailService` | тільки email |
| `Logger` | тільки логування |

## Запуск

```bash
npm install

# антипатерн
npm run antipattern

# рефакторинг
npm run refactored
```
